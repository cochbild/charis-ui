# Support

## Getting help

### Check the docs first

1. **[README](README.md)**: what Charis is, and how to try it.
2. **[The Charis Book](book/src/introduction.md)**: the guide, from a first app to docking,
   accessibility and testing.
3. **The API reference**: run `cargo doc --open` in the repository.
4. **[Existing issues](https://github.com/cochbild/charis-ui/issues)**: your question may have
   been answered already.

### Ask a question or report a problem

- **Open an issue** with the bug report or feature request template.
- For a general question, open an issue and describe what you're trying to build.

### What to include

- What you're trying to do, and what you've already tried.
- Error messages or logs.
- Your OS, Rust version (`rustc --version`) and the Charis commit you're on.
- For anything visual, a screenshot, and the lines `CHARIS_PROFILE=1` prints at startup (they
  name the renderer and GPU).

## Security issues

**Don't report security vulnerabilities in public issues.** See [SECURITY.md](SECURITY.md) for
how to report them privately.

## Response time

Charis is maintained as a personal project. I'll do my best to respond in a reasonable time,
but please be patient.
